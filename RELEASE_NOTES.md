Version 0.1.3: moved the original project credits to the end of the README. Download, installation, troubleshooting, licensing, and limitations guidance remains included.

- Portable Agent Skills layout with documented local destinations for Codex, Claude Code, Gemini CLI, Antigravity, and Freebuff CLI.
- Windows installer and removal helper with integrity checks and preserved backups.
- Local source search, GitHub API search, web-query links, game-folder inspection, declared binding review, and evidence-attachment checks.
- Guidance for real game APIs, simple key bindings, verified movement, speech backends, narrative accessibility, and truthful completion reports.
- Credited template/reference library and versioned research sources.

Compatibility paths are based on official documentation or inspected source. Local installer/helper tests do not certify live discovery or model behavior in every assistant. Completion examples support future behavioral evaluation; development test fixtures are excluded from the release. No hallucination-reduction percentage or full-game playability is claimed.

Download the full game-accessibility-mod-skill ZIP for the Windows installer. The smaller accessibility-mod-development skill ZIP contains only the skill folder for manual installation or compatible skill importers.
