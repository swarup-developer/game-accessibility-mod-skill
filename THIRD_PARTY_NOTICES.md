This package adapts [Happy Starfish / Plueschyoda's Accessibility-mod-template](https://github.com/HappyStarfish/Accessibility-mod-template) and [VIPPotato's Codex edition](https://github.com/VIPPotato/Accessibility-mod-template-Codex-edition). Thank you to their authors and contributors for the original accessibility workflow and code starters.

The original repository states CC BY 4.0. Its license files and attribution remain in `skills/accessibility-mod-development/references/template/LICENSE` and the local snapshot. The source manifest identifies 51 original GitHub files by immutable ref and blob ID. Local working copies are separate, identified snapshots; including them does not certify that their code has been tested in a game.

Changes include a portable entry point, focused completion rules, researched technical cautions, input and movement guidance, scenario examples, source indexing, a Windows installer, research helpers, package validation, and release tests.

The other GitHub projects and articles cited in research notes are sources for original technical summaries. Their implementation code and binaries are not included by the new research expansion. The externally linked Book of Accessibility Modding is not reproduced. A source link does not grant permission to copy or redistribute its contents.

No game assemblies, decompiled game source, saves, screen-reader binaries, or mod-loader binaries are included. Dependencies installed later have their own licenses.
